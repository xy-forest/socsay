# 苏格拉底如是说 （Socratic Questioning)

这是一个基于多模态感知的“认知防沉迷外挂”。它通过实时分析用户在编写 Prompt（提示词）时的面部表情与动作，判断其认知负荷与思考深度。如果在“未经深思”的状态下试图发送指令，系统会在操作系统底层直接拦截回车键，并驱动硬件摄像头给出物理层面的“拒绝”反馈，以此强制用户保持高质量的工作心流。

---

## 1. 核心架构与机制

本项目有三个干预层级，将传统的单向 Prompt 交互转化为双向的认知对齐：

1. **静默自适应层 (Silent Adaptation)**：后台以 30fps 实时监测用户的面部特征变化，当检测到持续的困惑或焦虑时，会将状态下发给关联的 AI 工具，使其自动调整回复的口吻与深度。
2. **状态可视化层 (Cognitive Mirror)**：通过 Web Dashboard 提供实时的“思考深度”数据流（包括平均紧张度、最高紧张度、采样数），将不可见的认知状态数据化。
3. **物理拦截层 (Physical Gate)**：当用户处于极度困惑或急躁状态下，并在特定 IDE（如 Cursor, VS Code）内强行按下 `Enter` 键时，系统会：
   - 在 OS 层面拦截并吞掉键盘事件。
   - 驱动桌面云台摄像头执行物理“摇头”。
   - 触发 TTS（文本转语音）模块，抛出具有启发性的“苏格拉底式反问”。
   - 当检测到用户表情从紧张转为平静（思考结束）时，摄像头“点头”并解锁回车键。

---

## 2. 项目技术栈及框架

本项目主要基于 Python 编写，采用端云结合的设计，核心技术选型如下：

*   **编程语言**: Python 3.10+
*   **视觉感知 (本地边缘)**: `OpenCV` (基于 Haar Cascades 进行极低延迟的人脸追踪与状态初筛)
*   **多模态大模型 (云端分析)**: `MiMo V2.5 API` (用于复杂微表情分析及高质量语音 TTS 合成)
*   **硬件控制**: 基于 UVC 协议的 PTZ 控制脚本（针对 Insta360 Link 2 定制的平移/俯仰电机控制）
*   **系统级钩子**: `pynput` (跨平台监听与拦截全局键盘事件)
*   **实时通信与控制台**: 原生 HTTP Server (`http.server`) + SSE (Server-Sent Events) 推送，前端采用 Vanilla JS 与无框架 HTML/CSS 构建极简高刷仪表盘。
*   **并发模型**: 原生 `threading` (解耦摄像头推流、本地视觉过滤、云端轮询与 HTTP 监听四个核心循环)。

> 本项目包含软硬件协同展示。**完整体验需要外接支持 PTZ 协议的云台摄像头（默认适配 Insta360 Link 2）**，用于展示系统的物理“点头 / 摇头”交互。
> 若无外接设备，系统将自动降级为“纯软件模式”（保留键盘拦截、Web 面板及语音 TTS 反馈）。

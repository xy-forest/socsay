# 苏格拉底如是说 (Socratic Companion)

**不要急着让 AI 做事，先让 AI 懂你。**

“苏格拉底如是说” 是一个带有“物理门禁”的认知外挂，通过多模态感知监控用户工作时的专注度、焦虑度，在用户产生不经过思考的“垃圾指令”前进行干预，辅助你养成高质量的深度工作心流。

---

## 1. 核心产品定位

| 维度 | 传统 AI 交互 | “苏格拉底如是说” 的降维打击 |
| :--- | :--- | :--- |
| **核心痛点** | 用户没想清楚就下指令，导致“垃圾进，垃圾出” | 拦截无脑指令，逼迫用户进行高质量思考 |
| **产品定位** | 讨好型的“执行工具”（自动售货机） | 严厉且懂你的“思想教练”（认知外挂） |
| **交互输入** | 只有文本（Prompt） | **多模态：文本 + 实时面部微表情/情绪** |
| **核心口号** | 帮您立刻完成任务！ | **不要急着让 AI 做事，先让 AI 懂你。** |

---

## 2. 核心功能：三层干预机制

| 层级 | 状态名称 | 触发条件（摄像头监测到...） | 系统行为（AI 与硬件如何反应） | 核心价值 |
| :---: | :--- | :--- | :--- | :--- |
| **层级一** | **静默自适应**<br>*(日常辅助)* | 监测到用户困惑 / 专注 / 焦虑等情绪变化，但未执行操作 | **动态优化 AI 回复：**<br>根据情绪调整 AI 的语气和深度（如：用户困惑时，AI 回答变得循循善诱；专注时，AI 给出精简干货） | 润物细无声的陪伴，**让 AI 读懂“情绪 Prompt”** |
| **层级二** | **认知镜像**<br>*(状态可视化)* | 实时监测用户的面部稳定度、眨眼频率、视线焦点 | **界面指示器：**<br>屏幕角落显示当前的“思考深度”或“认知负荷”状态灯 | 把抽象的思考过程**数据化、可视化**，像大脑的仪表盘 |
| **层级三** | **物理门禁**<br>*(极端干预)* | 用户在“极度困惑 / 未经深思”的状态下，**强行按下回车键** | **底层拦截与诘问：**<br>1. 吞掉回车键，中断执行<br>2. 硬件摄像头物理**摇头 🙅**<br>3. 语音发问：“你确定这是你要的答案吗？”<br>4. 用户想通后，硬件**点头 🙆**并放行 | 展台最具戏剧性的 Aha Moment，**真正的“物理刹车片”** |

## 3. 用户成长闭环与商业化

| 阶段 | 环节 | 具体表现 | 产生的用户价值 |
| :---: | :--- | :--- | :--- |
| **1. 察觉** | **多模感知** | 后台默默记录表情、动作、键盘输入状态 | 零打扰的数据收集 |
| **2. 刹车** | **物理干预** | 在用户企图“偷懒交差”时，拦住回车，抛出苏格拉底式反问 | 避免低质量产出，强制澄清意图 |
| **3. 引导** | **深度共脑** | 用户停下思考，AI 结合情绪状态给出最合适的启发式回复 | 帮助用户理清思路，跨越思维盲区 |
| **4. 复盘** | **思考报告** | 生成周报：本周“深度思考总时长”、“最佳心流时段”、“被拦截拯救次数” | **量化自我，极强的成就感与留存率（Pro 版付费点）** |

## 安装与运行

### 环境准备

本项目需要 Python 3.10+ 和 `pynput` 等系统级依赖（因涉及到键盘拦截，需赋予运行终端“辅助功能/无障碍”权限）。

```bash
# 1. 复制环境配置并填入你自己的 MiMo API Key
cp .env.example .env

# 2. 安装依赖
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. 运行主程序
python -m socsay.main
```

### 路演/演示建议 (Cheat Sheet)

1. **我们发现了什么？** —— 我们发现大家用 AI 越来越懒，产出越来越差。
2. **我们做了什么？** —— 我们做了一个能“看懂你表情”并在底层“锁死你键盘”的认知外挂。
3. **它是怎么运行的？** —— 当您没想清楚就按回车，它会摇头并吃掉您的指令，逼您三思；日常它则会根据您的表情，自动优化 AI 的回答。
4. **长期价值是什么？** —— 它不仅是防沉迷工具，更是您的“大脑健康管家”，每周为您生成“思考深度周报”，帮您养成顶级的工作心流。
